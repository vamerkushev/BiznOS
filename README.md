# БизнОС — Smart Business Calculator

Прототип умного бизнес-калькулятора с AI-инсайтами.

## Структура

- `index.html` — разметка страницы.
- `css/` — стили по слоям (переменные → база → каркас → компоненты → адаптив).
- `js/` — ES-модули: утилиты, состояние, логика расчёта, генерация инсайтов, рендер, импорт CSV, уведомления.
